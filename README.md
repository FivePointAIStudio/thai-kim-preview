# Thai Kim Textile — Website Preview

Static demonstration website containing 20 design concepts and a reference gallery.

Open the website: https://fivepointaistudio.github.io/thai-kim-preview/

This publication repository contains only the files served to visitors. It does not include the original private repository history, local runtime configuration, customer records or credentials.

All displayed products, prices, stock and chat recommendations are illustrative. No AI backend, database, orders, payments or actual enquiry submission is connected. The chat retains demo entries temporarily in the visitor’s own browser tab.

The preview website and its delivery files are publicly accessible. Original photo and third-party reference rights remain with their owners; see the asset credits within the site.
