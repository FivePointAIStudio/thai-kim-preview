Thai Kim Textile · 20 套官网设计提案

独立的高保真前端首页原型，供内部比较设计方向，不是 20 套生产系统。

内容与交互

20 种独立首页结构、中英泰文案、材料搜索与筛选、示例产品详情、索样清单、浏览器收藏、需求草稿下载、聊天 Demo、设计方案分享。对比页支持实拍预览图、长图、泰文手机图及 2—4 套并排比较。

聊天演示

比稿模式默认不遮挡设计；点击聊天入口即展开原有演示。直接访问方案时附加 &mode=customer 可自动展开聊天。首次发送时填写地区、手机号，称呼和介绍选填；BKK 固定默认、四个业务地区和其他地区；只做演示，无 IP 定位、短信验证、AI 调用或数据库。手机号仅由原聊天模块在当前标签页暂存。

不包含的生产功能

真实产品、库存、价格、客户匹配、订单、支付、CMS、账号和域名均未接入。正式数据只能来自你们自己的业务系统。样例价格不可用于实际报价。泰文、品牌层级、Logo 及任何商业承诺需本地团队上线前核验。
